# Debugging Playbooks for Common Production Issues

## Overview
Create repeatable incident debugging steps for API, database, and UI issues.

## Background
Shared playbooks help less experienced members contribute during incidents.

## Why this topic matters
The team can reduce mean time to understand and recover from failures.

## Target audience
- Backend Developer
- QA Engineer
- Frontend Developer
- Business Analyst

## Difficulty
Intermediate

## Expected impact
High

## Suggested agenda
1. Context and current team problem
2. Core concepts
3. Practical examples
4. Team discussion
