# System Design Basics for Feature Teams

## Overview
A practical introduction to system design decisions for small feature teams.

## Background
The team is touching more services and needs a shared language for tradeoffs.

## Why this topic matters
Better design conversations reduce rework and make implementation plans clearer.

## Target audience
- Backend Developer
- QA Engineer
- Frontend Developer
- Business Analyst

## Difficulty
Intermediate

## Expected impact
High

## Suggested agenda
1. Context and current team problem
2. Core concepts
3. Practical examples
4. Team discussion
